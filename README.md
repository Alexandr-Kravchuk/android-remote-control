# Допомога: віддалене керування Android-телефоном

Проєкт, щоб допомагати рідним (наприклад, батькам) з телефоном на відстані.
Ви бачите екран їхнього телефону в браузері на Mac, керуєте ним мишею й клавіатурою
і **одночасно розмовляєте голосом**. Сервером може бути ваш власний ноутбук.

```
 Телефон батька                          Ваш Mac
┌────────────────────┐                   ┌──────────────────────────────────────┐
│ Додаток «Допомога» │   екран (H.264)   │ server/ (Node.js)                    │
│ • екран            │ ────────────────▶ │  • :8080 — лише для телефонів ───────┼──▶ Tailscale Funnel
│ • дотики, текст    │ ◀──────────────── │  • localhost:8081 — пульт (браузер)  │    https://<mac>.ts.net
│ • голос            │  дотики, свайпи   │                                      │
└────────────────────┘                   └──────────────────────────────────────┘
          ▲                 голос (WebRTC, напряму між телефоном і браузером)    │
          └──────────────────────────────────────────────────────────────────────┘
```

* **`android/`** — додаток для телефону (Kotlin). Одна велика кнопка «Отримати допомогу»,
  після натискання з'являється 6-значний код, який людина диктує вам.
* **`server/`** — невеликий сервер на Node.js: з'єднує телефон і ваш браузер за кодом
  і віддає веб-пульт (`server/public`). Нічого не записує й не зберігає.

## Що вміє

| Ви (у браузері)                              | Що відбувається на телефоні                |
|----------------------------------------------|--------------------------------------------|
| Клік мишею                                   | Дотик                                      |
| Перетягування                                | Свайп (працює і графічний ключ)            |
| Утримання кнопки миші 0,6 с                  | Довге натискання                           |
| Коліщатко / жест на тачпаді                  | Прокрутка                                  |
| Друк на клавіатурі (будь-яка розкладка), Cmd+V | Текст у поле, де стоїть курсор           |
| Esc / «Назад», «Додому», «Програми»          | Системні кнопки                            |
| Сповіщення, швидкі налаштування, меню живлення, блокування, скріншот | Відповідні системні дії |
| **📞 Почати розмову**                        | Голосовий зв'язок через гучномовець, телефон відповідає сам |
| «Повідомлення на телефон»                    | Великий банер з вашим текстом поверх усього |

Додатково: модель телефону й заряд батареї, індикатор якості зв'язку, вибір якості
зображення, автоматичне перепідключення.

### Робота при поганому зв'язку

* **Відео H.264** з апаратного кодека телефону: у 5–10 разів менше трафіку, ніж знімки екрана.
  Якщо браузер не вміє H.264, використовується JPEG.
* **Адаптивний бітрейт:** кожен кадр підтверджується, тож телефон знає реальну затримку.
  Коли канал не справляється, телефон **пропускає кадри замість накопичувати затримку**,
  знижує бітрейт, а за дуже слабкого каналу ще й роздільність. Коли зв'язок покращується,
  якість піднімається назад. Нерухомий екран майже нічого не передає.
* Режим **«Економ»** для дуже слабкого інтернету (≈80–600 кбіт/с, 10 кадр/с).
* **Голос через WebRTC (Opus)**: компенсація втрат, корекція помилок (FEC), буфер тремтіння,
  ехоподавлення. Близько 20–30 кбіт/с, тож голос працює навіть тоді, коли картинка гальмує.
* Телефон, що втратив мережу, повертається в **ту саму сесію з тим самим кодом**
  протягом 3 хвилин. Голосовий канал окремий і часто переживає такі обриви.
* Команди (дотики, текст) займають байти і проходять навіть на 2G/EDGE.

## Крок 1. Сервер на вашому Mac (рекомендовано)

Телефон зазвичай у мобільній мережі, тож Mac потрібна публічна HTTPS-адреса. Найпростіше
й безкоштовно це зробити через **Tailscale Funnel**: адреса постійна (`https://<ім'я-mac>.<tailnet>.ts.net`),
не потрібні домен, налаштування роутера чи білий IP. На телефон батька Tailscale **не** потрібен.

Один раз:

1. Встановіть [Node.js](https://nodejs.org) (або `brew install node`).
2. Встановіть [Tailscale для Mac](https://tailscale.com/download/mac) і увійдіть.
3. Увімкніть Funnel: в [адмін-панелі Tailscale](https://login.tailscale.com/admin/dns) увімкніть
   *HTTPS Certificates*. Під час першого запуску `tailscale funnel` покаже посилання, щоб
   дозволити Funnel для цього Mac.
4. Склонуйте репозиторій.

Щоразу, коли треба допомогти:

* двічі клацніть **`server/mac/Запустити допомогу.command`** (або `./server/mac/start.sh` у Терміналі).
  Скрипт запустить сервер і Funnel, не дасть Mac заснути й відкриє пульт `http://localhost:8081`.
  Під час першого запуску він покаже **адресу для телефону**: її вшивають у додаток (крок 2).

Безпека в цьому режимі: з інтернету доступний **лише** вхід для телефонів (порт 8080).
Пульт помічника слухає тільки `127.0.0.1:8081`, тому підключитися до сесії як помічник
можна лише з вашого Mac.

Важливо: поки Mac вимкнений, спить або закрита кришка, сервер недоступний. Тато натисне
кнопку і побачить «Немає інтернету. Перепідключення…». Щойно ви запустите сервер,
телефон підключиться сам.

<details>
<summary>Альтернативи Tailscale Funnel</summary>

* **Cloudflare Tunnel** з власним доменом (`cloudflared tunnel ...` → `http://localhost:8080`).
  Тимчасові адреси `trycloudflare.com` не підходять, бо змінюються щоразу.
* **Проброс порту на роутері** + DDNS + HTTPS (наприклад, Caddy).
* Запуск: `TUNNEL=none ./server/mac/start.sh` або `npm run laptop` у `server/`.
</details>

<details>
<summary>Сервер на VPS (якщо Mac не завжди увімкнений)</summary>

```bash
cd server
DOMAIN=help.example.com ACCESS_TOKEN=$(openssl rand -hex 16) docker compose up -d
```

Caddy сам отримає HTTPS-сертифікат. У цьому режимі пульт публічний, тому
`ACCESS_TOKEN` **обов'язковий**: щонайменше 16 символів, інакше сервер не запуститься. Ключ один раз вводиться
на сторінці пульта, і браузер його запам'ятовує. Підбір обмежено: 20 невдалих спроб з однієї IP за 10 хвилин; при масових
спробах з різних адрес сервер сповільнює відповіді, але вас із правильним ключем не блокує.
</details>

### Якщо голос не з'єднується (TURN)

Голос іде напряму між браузером і телефоном. Зазвичай це працює, але деякі мобільні
оператори й корпоративні мережі не пропускають прямі з'єднання. Тоді пульт напише
«Не вдається з'єднати голос напряму». Керування при цьому працює як і раніше.

Варіанти: подзвонити звичайним дзвінком на гучномовець, паралельно з керуванням
(зручно й надійно), або додати TURN-сервер. Наприклад, безкоштовний тариф metered.ca
чи Cloudflare TURN; голосу потрібно лише ~15 МБ на годину:

```bash
TURN_URLS=turns:turn.example.com:443?transport=tcp TURN_USERNAME=... TURN_CREDENTIAL=... ./server/mac/start.sh
```

## Крок 2. Зібрати APK

**Через GitHub Actions (нічого не встановлюючи):**

1. *Settings → Secrets and variables → Actions → Variables*: додайте змінну
   `REMOTE_HELP_SERVER` = адреса з кроку 1 (наприклад, `https://my-mac.tail1234.ts.net`).
2. *(Рекомендовано)* Стабільний ключ підпису, щоб оновлення ставилися поверх старої версії:
   ```bash
   keytool -genkeypair -keystore release.jks -alias remotehelp -keyalg RSA -keysize 2048 -validity 10000
   base64 -i release.jks | pbcopy
   ```
   Додайте *Secrets*: `KEYSTORE_BASE64` (вставити), `KEYSTORE_PASSWORD`, `KEY_ALIAS` (`remotehelp`),
   `KEY_PASSWORD`. Файл `release.jks` збережіть у надійному місці й **не** комітьте.
3. *Actions → Build → Run workflow*, потім завантажте артефакт `remote-help-apk`.

**Локально** (JDK 17+ і Android SDK, наприклад з Android Studio):

```bash
cd android
./gradlew assembleRelease -PremoteHelpServer=https://my-mac.tail1234.ts.net
# APK: android/app/build/outputs/apk/release/app-release.apk
```

Адресу сервера також можна змінити в самому додатку (кнопка ⚙).

## Крок 3. Встановити на телефон батька (один раз)

Найпростіше зробити це поруч або по відеодзвінку.

1. Перешліть APK у месенджер або на пошту й відкрийте його на телефоні. Дозвольте встановлення
   з цього джерела.
2. Відкрийте **«Допомога»**. Якщо вгорі жовта картка «Керування вимкнено»:
   * **«Відкрити налаштування»** → *Встановлені / Завантажені програми* → **«Допомога — керування»** → увімкнути;
   * **Android 13+:** якщо перемикач сірий («Обмежене налаштування»), відкрийте
     *Налаштування → Програми → Допомога → ⋮ → «Дозволити обмежені налаштування»* і поверніться.
3. Натисніть велику кнопку й **дозвольте мікрофон** (для розмови) та сповіщення.
4. Xiaomi / Huawei / деякі Samsung: *Програми → Допомога → Батарея → «Без обмежень»*.
5. Винесіть іконку «Допомога» на головний екран.

## Як користуватися

**Батькові (на телефоні):**
1. Відкрити «Допомога» і натиснути зелену кнопку **ОТРИМАТИ ДОПОМОГУ**.
2. У системному вікні натиснути **«Почати»** (Android питає щоразу; це захист).
3. Продиктувати вам 6 цифр з екрана.
4. Коли ви почнете розмову, телефон заговорить через гучномовець. Є велика кнопка
   «Вимкнути мікрофон».
5. Коли закінчили, натиснути червону кнопку **ЗУПИНИТИ** (або «Зупинити» у сповіщенні).

**Вам (на Mac):**
1. Запустити сервер (крок 1), пульт відкриється сам: `http://localhost:8081`.
2. Ввести код → «Підключитися». Натиснути **📞 Почати розмову** і дозволити мікрофон.
3. Клікнути по зображенню телефону й керувати. Вгорі видно якість зв'язку.
4. Якщо зв'язок поганий, оберіть якість **«Економ»**.

## Безпека

* Ніхто не підключиться, поки людина сама не натисне кнопку й не підтвердить системний запит
  на показ екрана. Код діє лише до кінця сесії.
* Під час сесії Android показує значок трансляції та сповіщення з кнопкою «Зупинити».
  Якщо помічник перепідключився, на телефоні з'являється повідомлення.
* Сервер нічого не зберігає й не бачить голосу: голос іде напряму (DTLS-SRTP), сервер
  пересилає лише службові повідомлення.
* У режимі ноутбука пульт недоступний з інтернету. У режимі VPS обов'язковий `ACCESS_TOKEN`
  і діє обмеження спроб.

## Обмеження

* Екран має бути розблокований: ввести PIN за людину на заблокованому екрані не вийде.
* Банківські програми й частина полів пароля забороняють знімати екран, і ви побачите
  чорний прямокутник. Керування при цьому працює.
* Кнопки гучності й фізичну кнопку живлення натиснути не можна (є меню живлення та блокування).
* Пульт потребує сучасного браузера: Chrome, Edge або Safari 16.4+ (для H.264; старіші
  отримають JPEG).
* Що перевірено: збирання й статичний аналіз Android-проєкту; автотести сервера (протокол,
  обидва режими запуску); наскрізний тест пульта в Chromium з імітацією телефона (H.264-відео,
  JPEG, дотики, текст, голосове з'єднання WebRTC). **На реальному телефоні ще не перевірено**:
  обов'язково спробуйте на своєму Android перед тим, як віддавати батькові.

Готові альтернативи: RustDesk (відкритий код), AnyDesk, TeamViewer QuickSupport.

## Структура

```
android/app/src/main/java/ua/remotehelp/
  MainActivity.kt          екран з великою кнопкою, кодом і кнопкою мікрофона
  ScreenShareService.kt    сесія: WebSocket, команди, сповіщення
  ScreenStreamer.kt        MediaProjection → H.264 (MediaCodec) / JPEG, адаптивний бітрейт
  VoiceCall.kt             голос через WebRTC
  ControlService.kt        AccessibilityService: дотики, свайпи, текст, системні кнопки
server/
  server.js                ретранслятор + пульт; режими «ноут» (CONSOLE_PORT) і «VPS»
  public/                  веб-пульт (HTML/CSS/JS, без збірки): WebCodecs, WebRTC
  mac/start.sh             запуск на Mac + Tailscale Funnel
  test/                    автотести
  Dockerfile, docker-compose.yml, Caddyfile   для VPS
```

### Протокол (WebSocket)

* Телефон → `/ws/device`: `hello {name, code?, secret?}` → `registered {code, secret, iceServers}`.
* Помічник → `/ws/viewer`: `join {code, token?}` → `joined {name, iceServers}` / `error`.
* Бінарні кадри від телефону: `[тип:1][id:4][дані]`, де тип 1 — ключовий кадр H.264
  (Annex B з SPS/PPS), 2 — різницевий кадр H.264, 3 — JPEG. Помічник відповідає `ack {id}`
  на кожен кадр.
* Помічник → телефон: `caps {h264}`, `quality {level: auto|low|high}`, `keyframe`,
  `tap {x,y}`, `longpress`, `swipe {points, duration}`, `scroll {x,y,dx,dy}`,
  `global {action}`, `text {text}`, `key {key}`, `message {text}`,
  `rtc-offer {sdp}`, `rtc-ice`, `call-end`, `end-session`. Координати нормалізовані (0…1).
* Телефон → помічник: `screen`, `stream {mode}`, `stats {rtt, bitrate, drops, fps}`, `info`,
  `notice`, `a11y`, `rtc-answer`, `rtc-ice`, `call-state`, `call-unavailable`, `bye`.
