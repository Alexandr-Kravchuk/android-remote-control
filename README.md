# Допомога: віддалене керування Android-телефоном

Проєкт для того, щоб допомагати рідним (наприклад, батькам) з телефоном на відстані.
Ви бачите екран їхнього телефону у браузері на Mac і керуєте ним мишею та клавіатурою.

```
 Телефон батька                    Сервер-ретранслятор                Ваш Mac
┌──────────────────┐   WebSocket   ┌─────────────────┐   WebSocket   ┌──────────────────┐
│ Додаток «Допомога»│ ───────────▶ │  server/ (Node) │ ◀──────────── │ Браузер: веб-пульт│
│ • екран (JPEG)    │  кадри екрана │ • видає 6-значний│  дотики, свайпи│ • бачите екран    │
│ • виконує дотики  │ ◀─────────── │   код сесії      │  текст, кнопки │ • керуєте мишею   │
└──────────────────┘               │ • пересилає дані │               └──────────────────┘
                                   └─────────────────┘
```

* **`android/`** — додаток для телефону (Kotlin). Одна велика кнопка «Отримати допомогу»,
  після натискання показує код, який людина диктує вам.
* **`server/`** — невеликий сервер на Node.js: з’єднує телефон і ваш браузер за кодом,
  а також віддає веб-пульт (`server/public`). Нічого не записує й не зберігає.

## Що вміє

| Ви (у браузері)                          | Що відбувається на телефоні            |
|------------------------------------------|----------------------------------------|
| Клік мишею                               | Дотик                                  |
| Перетягування                            | Свайп (працює і графічний ключ)        |
| Утримання кнопки миші 0,6 с              | Довге натискання                       |
| Коліщатко / жест на тачпаді              | Прокрутка                              |
| Друк на клавіатурі (будь-яка розкладка), Cmd+V | Текст у поле, де стоїть курсор   |
| Esc / кнопки «Назад», «Додому», «Програми» | Системні кнопки                      |
| Сповіщення, швидкі налаштування, меню живлення, блокування, скріншот | Відповідні системні дії |
| «Повідомлення на телефон»                | Великий банер з вашим текстом поверх усього |

Також: показ моделі та заряду батареї, вибір якості зображення (для слабкого інтернету),
автоматичне перепідключення, якщо телефон на хвилину втратив мережу.

---

## Крок 1. Розгорнути сервер

Серверу потрібна публічна адреса з HTTPS, бо телефон і Mac зазвичай у різних мережах.

### Варіант А: VPS (найнадійніше)

Будь-який VPS за ~$4–5/міс (Hetzner, DigitalOcean тощо) і домен (або піддомен), що вказує на нього:

```bash
git clone <цей репозиторій> && cd android-remote-control/server
DOMAIN=help.example.com ACCESS_TOKEN=$(openssl rand -hex 16) docker compose up -d
```

Caddy автоматично отримає безкоштовний HTTPS-сертифікат. Запишіть значення `ACCESS_TOKEN`:
його потрібно один раз ввести на сторінці пульта (поле «Ключ доступу до сервера»), браузер
його запам’ятає.

### Варіант Б: хмарний хостинг (Render, Fly.io, Railway)

Створіть сервіс з папки `server/` (є `Dockerfile`), задайте змінні середовища
`ACCESS_TOKEN=<довгий випадковий рядок>` і `TRUST_PROXY=1`. HTTPS ці сервіси дають самі.
Важливо: хостинг має підтримувати WebSocket (усі три перелічені підтримують). На безкоштовних
тарифах сервер може «засинати» — перше підключення тоді триває 30–60 с.

### Перевірка локально

```bash
cd server && npm install && npm start      # http://localhost:8080
npm test                                    # перевірка протоколу
```

Змінні середовища: `PORT` (8080), `ACCESS_TOKEN` (рекомендовано), `TRUST_PROXY=1` (за проксі).

## Крок 2. Зібрати APK

**Через GitHub Actions (нічого не встановлюючи):**

1. У репозиторії: *Settings → Secrets and variables → Actions → Variables* → додайте змінну
   `REMOTE_HELP_SERVER` = `https://help.example.com` (адреса вашого сервера).
2. *(Рекомендовано)* Додайте стабільний ключ підпису, щоб оновлення встановлювалися поверх
   старої версії. Один раз створіть ключ:
   ```bash
   keytool -genkeypair -keystore release.jks -alias remotehelp -keyalg RSA -keysize 2048 -validity 10000
   base64 -i release.jks | pbcopy     # macOS: скопіює в буфер обміну
   ```
   і додайте *Secrets*: `KEYSTORE_BASE64` (вставити з буфера), `KEYSTORE_PASSWORD`,
   `KEY_ALIAS` (`remotehelp`), `KEY_PASSWORD`. Файл `release.jks` збережіть у надійному місці,
   **не** комітьте в репозиторій.
3. *Actions → Build → Run workflow*. Після завершення завантажте артефакт `remote-help-apk`.

**Локально** (потрібні JDK 17+ і Android SDK, наприклад з Android Studio):

```bash
cd android
./gradlew assembleRelease -PremoteHelpServer=https://help.example.com
# APK: android/app/build/outputs/apk/release/app-release.apk
```

Адресу сервера також можна змінити прямо в додатку (кнопка ⚙).

## Крок 3. Встановити на телефон батька (один раз)

Найпростіше зробити це, коли ви поруч, або по відеодзвінку.

1. Перешліть APK у месенджер / на пошту й відкрийте його на телефоні. Android попросить дозволити
   встановлення з цього джерела — дозвольте.
2. Відкрийте **«Допомога»**. Якщо зверху жовта картка «Керування вимкнено»:
   * натисніть **«Відкрити налаштування»** → *Встановлені програми / Завантажені програми* →
     **«Допомога — керування»** → увімкнути;
   * **Android 13+:** якщо перемикач сірий і пише «Обмежене налаштування» — відкрийте
     *Налаштування → Програми → Допомога → ⋮ (вгорі праворуч) → «Дозволити обмежені налаштування»*,
     потім поверніться і увімкніть.
3. Натисніть велику кнопку і дозвольте сповіщення — перевірте, що з’являється код.
4. На Xiaomi/Huawei/деяких Samsung: *Програми → Допомога → Батарея* → «Без обмежень», щоб система
   не обривала сесію.
5. Винесіть іконку «Допомога» на головний екран на видне місце.

## Як користуватися

**Батькові (на телефоні):**
1. Відкрити «Допомога» → натиснути зелену кнопку **ОТРИМАТИ ДОПОМОГУ**.
2. У системному вікні натиснути **«Почати»** / «Start now» (Android питає щоразу — це захист).
3. Продиктувати вам 6 цифр, які з’явились на екрані.
4. Коли закінчили — натиснути червону кнопку **ЗУПИНИТИ** (або «Зупинити» у сповіщенні).

**Вам (на Mac):**
1. Відкрити `https://help.example.com` у Safari/Chrome, ввести код → «Підключитися».
2. Клікнути по зображенню телефону — і можна керувати мишею та друкувати.
3. Щоб мати «додаток» у Dock: у Safari *Файл → Додати в Dock* (macOS Sonoma і новіші),
   у Chrome — *⋮ → Трансляція, збереження й надсилання → Установити сторінку як додаток*.

Якщо ви закрили вкладку — телефон продовжує чекати, можна підключитися знову з тим самим кодом.

## Безпека

* Ніхто не може підключитися, поки людина сама не натисне кнопку і не підтвердить системний
  запит на показ екрана. Код діє лише до кінця сесії.
* Під час сесії в рядку стану Android завжди видно значок трансляції, є сповіщення з кнопкою «Зупинити».
* Сервер нічого не зберігає, лише пересилає дані між одним телефоном і одним помічником.
  Підбір кодів обмежено (20 невдалих спроб на 10 хвилин з однієї IP), а з `ACCESS_TOKEN`
  без ключа підключитися неможливо взагалі. **Встановіть `ACCESS_TOKEN`.**
* Використовуйте лише HTTPS-адресу сервера: тоді трафік шифрується.

## Обмеження

* Екран має бути розблокований: ввести PIN за людину на заблокованому екрані не вийде.
* Деякі програми (банківські, частина полів пароля, захищене відео) забороняють знімати екран —
  ви побачите чорний прямокутник. Керування дотиками при цьому працює.
* Кнопки гучності та фізичну кнопку живлення натиснути не можна (є меню живлення та блокування).
* Зображення передається кадрами JPEG (до ~8–14 кадрів/с) — для налаштувань і програм цього
  достатньо, для відео — ні.
* Перевірено: збірка й статичний аналіз Android-проєкту, автоматичний тест сервера та веб-пульта
  з імітацією телефона. Перед тим як віддавати батькові, перевірте на реальному телефоні.

Готові альтернативи, якщо не хочеться підтримувати власний сервер: RustDesk (відкритий код),
AnyDesk, TeamViewer QuickSupport.

## Структура

```
android/                         Android-додаток (minSdk 26 / Android 8, targetSdk 35)
  app/src/main/java/ua/remotehelp/
    MainActivity.kt              екран з великою кнопкою і кодом
    ScreenShareService.kt        MediaProjection → JPEG → WebSocket, приймає команди
    ControlService.kt            AccessibilityService: дотики, свайпи, текст, системні кнопки
server/
  server.js                      ретранслятор (ws) + віддача веб-пульта
  public/                        веб-пульт (HTML/CSS/JS, без збірки)
  test/smoke.js                  перевірка протоколу
  Dockerfile, docker-compose.yml, Caddyfile
```

### Протокол (JSON через WebSocket)

* Телефон → `/ws/device`: `hello {name, code?, secret?}` → сервер: `registered {code, secret}`.
  Далі бінарні повідомлення = JPEG-кадри; також `screen`, `info`, `notice`, `a11y`, `bye`.
* Помічник → `/ws/viewer`: `join {code, token?}` → `joined` / `error`.
  Команди: `tap {x,y}`, `longpress {x,y}`, `swipe {points:[[x,y]…], duration}`,
  `scroll {x,y,dx,dy}`, `global {action}`, `text {text}`, `key {key}`, `message {text}`,
  `quality {level}`, `ack` (підтвердження кадру — керування швидкістю), `end-session`.
  Координати нормалізовані (0…1).
